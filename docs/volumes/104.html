（104-01）奉和九日幸臨渭亭登高應制得餘字五律

蕭至忠
望幸三秋暮，登高九日初。
朱旗巡漢苑，翠帟俯秦墟。
寵極萸房遍，恩深菊酎餘。
承歡何以答，萬億奉宸居。

（104-02）奉和九月九日登慈恩寺浮圖應制五律

蕭至忠
天蹕三乘啟，星輿六轡行。
登高淩寶塔，極目遍王城。
神衛空中繞，仙歌雲外清。
重陽千萬壽，率舞頌升平。

（104-03）奉和幸安樂公主山莊應制七律

蕭至忠
西郊窈窕鳳皇臺，北渚平明法駕來。
匝地金聲初度曲，周堂玉溜好傳杯。
灣路分遊畫舟轉，岸門相向碧亭開。
微臣此時承宴樂，髣髴疑從星漢迴。

（104-04）送張亶赴朔方應制五言排律

蕭至忠
命將擇耆年，圖功勝必全。
光輝萬乘餞，威武二庭宣。
中衢橫鼓角，曠野蔽旌旃。
推食天廚至，投醪禦酒傳。
涼風過雁苑，殺氣下雞田。
分閫恩何極，臨岐動睿篇。

（104-05）陪幸長寧公主林亭五律

蕭至忠
公主林亭地，清晨降玉輿。
畫橋飛渡水，仙閣迥臨虛。
新晴看蛺蝶，早夏摘芙蕖。
文酒娛游盛，忻叨侍從餘。

（104-06）陪幸五王宅五言排律

蕭至忠
北斗樞機任，西京肺腑親。
疇昔王門下，今茲制幸晨。
恩來山水被，聖作管弦新。
繞座熏紅藥，當軒暗綠筠。
摘荷才早夏，聽鳥尚餘春。
行漏金徒曉，風煙是觀津。

（104-07）三會寺應制五言排律

蕭至忠
岧嶢倉史台，敞朗紺園開。
戒旦壺人警，翻霜羽騎來。
下輦登三襲，褰旒望九垓。
林披館陶榜，水浸昆明灰。
網戶飛花綴，幡竿度鳥回。
豫遊仙唱動，瀟灑出塵埃。

（104-08）薦福寺應制雜言

蕭至忠
地靈傳景福，天駕儼鉤陳。
佳哉藩邸舊，赫矣梵宮新。
香塔魚山下，禪堂鴈水濱。
珠幡映白日，鏡殿寫青春。
甚懽延故吏，大覺拯生人。
幸承歌頌末，長奉屬車[塵]。

（104-09）陪游上苑遇雪七絕

蕭至忠
龍驂曉入望春宮，正逢春雪舞春風。
花光並在天文上，寒氣行銷禦酒中。

（104-10）奉和九日幸臨渭亭登高應制得風字五律

李迥秀
重九臨商節，登高出漢宮。
正逢萸實滿，還對菊花叢。
霽雲開就日，仙藻麗秋風。
微臣預在鎬，竊抃遂無窮。

（104-11）奉和九月九日登慈恩寺浮圖應制雜言

李迥秀
沙界人王塔，金繩梵帝遊。
言從[祇]樹賞，行翫菊叢秋。
御酒調甘露，天花拂綵旒。
堯年將佛日，同此慶時休。

（104-12）奉和幸安樂公主山莊應制七律

李迥秀
詰旦重門聞警蹕，傳言太主奏山林。
是日迴輿羅萬騎，此時歡喜賜千金。
鷺羽鳳簫參樂曲，荻園竹徑接帷陰。
手舞足蹈方無已，萬年千歲奉薰琴。

（104-13）夜宴安樂公主宅七絕

李迥秀
金榜岧嶢雲裏開，玉簫參差天際回。
莫驚側弁還歸路，只為平陽歌舞催。

（104-14）奉和九日幸臨渭亭登高應制得亭字五律

楊廉
遠目瞰秦坰，重陽坐灞亭。
既開黃菊酒，還降紫微星。
簫鼓諳仙曲，山河入畫屏。
幸茲陪宴喜，無以效丹青。

（104-15）奉和九月九日登慈恩寺浮圖應制五律

楊廉
萬乘臨真境，重陽眺遠空。
慈雲浮雁塔，定水映龍宮。
寶鐸含飆響，仙輪帶日紅。
天文將瑞色，輝煥滿寰中。

（104-16）奉和九日幸臨渭亭登高應制得枝字五律

韋安石
重九開秋節，得一動宸儀。
金風飄菊蕊，玉露泫萸枝。
睿覽八紘外，天文七曜披。
臨深應在即，居高豈忘危。

（104-17）侍宴旋師喜捷應制五律

韋安石
蜂蟻屯夷落，熊羆逐漢飛。
忘軀百戰後，屈指一年歸。
厚眷紓天藻，深慈解禦衣。
興酣歌舞出，朝野歎光輝。

（104-18）梁王宅侍宴應制同用風字五律

韋安石
梁園開勝景，軒駕動宸衷。
早荷承湛露，修竹引熏風。
九醞傾鐘石，百獸協絲桐。
小臣陪宴鎬，獻壽奉維嵩。

（104-19）奉和九日幸臨渭亭登高應制得明字五律

竇希玠
鑾輿巡上苑，鳳駕瞰層城。
御座丹烏麗，宸居白鶴驚。
玉旗縈桂葉，金杯泛菊英。
九晨陪聖膳，萬歲奉承明。

（104-20）奉和九日幸臨渭亭登高應制得臣字五律

陸景初
九秋光順豫，重節霽良辰。
登高識漢苑，問道侍軒臣。
菊花浮秬鬯，萸房插縉紳。
聖化邊陲謐，長洲鴻雁賓。

（104-21）奉和九日幸臨渭亭登高應制得日字五律

鄭南金
重陽玉律應，萬乘金輿出。
風起韻虞弦，雲開吐堯日。
菊花浮聖酒，茱香掛衰質。
欲知恩煦多，順動觀秋實。

（104-22）奉和九日幸臨渭亭登高應制得直字五律

李咸
重陽乘令序，四野開晴色。
日月數初並，乾坤聖登極。
菊黃迎酒泛，松翠淩霜直。
遊海難為深，負山徒倦力。

（104-23）奉和九日幸臨渭亭登高應制得花字五律

趙彥伯
九日報仙家，三秋轉歲華。
呼鷹下鳥路，戲馬出龍沙。
簪掛丹萸蕊，杯浮紫菊花。
所願同微物，年年共辟邪。

（104-24）從宴桃花園詠桃花應制七絕

趙彥伯
紅萼競燃春苑曙，䒠茸新吐禦筵開。
長年願奉西王宴，近侍慚無東朔才。

（104-25）苑中遇雪應制七絕

趙彥伯
千鐘聖酒禦筵披，六出祥英亂繞枝。
即此神仙對瓊圃，何煩轍跡向瑤池。

（104-26）奉和九日幸臨渭亭登高應制得樽字五律

於經野
禦氣三秋節，登高九曲門。
桂筵羅玉俎，菊醴溢芳樽。
遵渚歸鴻度，承雲舞鶴鶱。
微臣濫陪賞，空荷聖明恩。

（104-27）奉和九日幸臨渭亭登高應制得還字五律

盧懷慎
時和素秋節，宸豫紫機關。
鶴似聞琴至，人疑宴鎬還。
曠望臨平野，潺湲俯暝灣。
無因酬大德，空此愧崇班。

（104-28）奉和聖制龍池篇七律

盧懷慎
代邸東南龍躍泉，清漪碧浪遠浮天。
樓臺影就波中出，日月光疑鏡裏懸。
雁沼回流成舜海，龜書薦祉應堯年。
大川既濟慙爲檝，報德空思奉細涓。
