（633-61）攜仙籙九首七言古體

決事還須更事酬，清譚妙理一時休。
漁翁亦被機心誤，眼暗汀邊結釣鉤。
跡不趨時分不侯，功名身外最悠悠。
聽君總畫麒麟閣，還我閑眠舴艋舟。
仙凡路阻兩難留，煙樹人間一片秋。
若道陰功能濟活，且將方寸自焚修。
若有陰功救未然，玉皇品籍亦搜賢。
應知譚笑還高謝，別就滄洲贊上仙。
英名何用苦搜奇，不朽才銷一句詩。
卻賴風波阻三島，老臣猶得戀明時。
剪取紅雲剩寫詩，年年高會趁花時。
水精樓閣分明見，只欠霞漿別著旗。
此生得作太平人，只向塵中便出塵。
移取碧桃花萬樹，年年自樂故鄉春。

只為從來偏護惜，窗前今賀主人歸。
山中只是惜珍禽，語不分明識爾心。
若使解言天下事，燕台今築幾千金。
阻他羅網到柴扉，不奈偷倉雀轉肥。
賴爾林塘添景趣，剩留山果引教歸。

（633-68）虞鄉北原七絕

司空圖
澤北村貧煙火獰，稚田冬旱倩牛耕。
老人惆悵逢人訴，開盡黃花麥未金。

（633-69）洛中三首七言古體

司空圖
秋風團扇未驚心，笑看妝台落葉侵。
繡鳳不教金縷暗，青樓何處有寒砧。
不用頻嗟世路難，浮生各自系悲歡。
風霜一夜添羈思，羅綺誰家待早寒。
燕巢空後誰相伴，鴛被縫來不忍熏。
薄命敢辭長滴淚，倡家未必肯留君。

（633-70）寓筆七絕

司空圖
年年鑷鬢到花飄，依舊花繁鬢易凋。
撩亂一場人更恨，春風誰道勝輕飆。

（633-71）戲題試衫七絕

司空圖
朝班盡說人宜紫，洞府應無鶴著緋。
從此玉皇須破例，染霞裁賜地仙衣。

（633-72）汴柳半枯因悲柳中隱七絕

司空圖
行人莫歎前朝樹，已占河堤幾百春。
惆悵題詩柳中隱，柳衰猶在自無身。

（633-73）上方七絕

司空圖
花落更同悲木落，鶯聲相續即蟬聲。
榮枯了得無多事，只是閒人漫系情。

（633-74）寄王贊學七絕

司空圖
黃卷不關兼濟業，青山自保老閑身。
一行萬里纖塵靜，可要張儀更入秦。

（633-75）新節七絕

司空圖
轉悲新歲重於山，不似輕鷗肯複還。
朱紱縱教金印換，青雲未勝白頭閑。

（633-76）自河西歸山二首七律

司空圖
一水悠悠一葉危，往來長恨阻歸期。
鄉關不是無華表，自為多驚獨上遲。
水闊風驚去路危，孤舟欲上更遲遲。
鶴群長擾三珠樹，不借人間一隻騎。

（633-77）王官二首七律

司空圖
風荷似醉和花舞，沙鳥無情伴客閑。
總是此中皆有恨，更堪微雨半遮山。
荷塘煙罩小齋虛，景物皆宜入畫圖。
盡日無人只高臥，一雙白鳥隔紗廚。

（633-78）賀翰林侍郎二首七律

司空圖
太白東歸鶴背吟，鏡湖空在酒船沈。
今朝忽見銀台事，早晚重征入翰林。
玉版征書洞裏看，沈羲新拜侍郎官。
文星喜氣連台曜，聖主方知四海安。

（633-79）寄王十四舍人七絕

司空圖
幾年汶上約同遊，擬為蓮峰別置樓。
今日鳳凰池畔客，五千仞雪不回頭。

（633-80）綸閣有感七絕

司空圖
風濤曾阻化鱗來，誰料蓬瀛路卻開。
欲去遲遲還自笑，狂才應不是仙才。
