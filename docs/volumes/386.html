黑紗方帽君邊得，稱對山前坐竹床。
唯恐被人偷剪樣，不曾閑戴出書堂。

（386-98）題僧院七絕

張籍
聞師行講青龍疏，本寺住來多少年。
靜掃空房唯獨坐，千莖秋竹在簷前。

（386-99）送元八七絕

張籍
百神齋祭相隨遍，尋竹看山亦共行。
明日城西送君去，舊遊重到獨題名。

（386-100）吳楚歌詞七絕

張籍
庭前春鳥啄林聲，紅夾羅襦縫未成。
今朝社日停針線，起向朱櫻樹下行。

（386-101）題方睦上人月臺觀七絕

張籍
一身清淨無童子，獨坐空堂得幾年。
每夜焚香通月觀，可憐光影最團圓。

（386-102）華山廟七絕

張籍
金天廟下西京道，巫女紛紛走似煙。
手把紙錢迎過客，遣求恩福到神前。

（386-103）病中酬元宗簡七絕

張籍
東風漸暖滿城春，獨佔幽居養病身。
莫說櫻桃花已發，今年不作看花人。

（386-104）寺宿齋七絕

張籍
晚到金光門外寺，寺中新竹隔簾多。
齋官禁與僧相見，院院開門不得過。

（386-105）贈施肩吾七絕

張籍
世間漸覺無多事，雖有空名未著身。
合取藥成相待吃，不須先作上天人。

（386-106）贈王建七絕

張籍
白君去後交遊少，東野亡來篋笥貧。
賴有白頭王建在，眼前猶見詠詩人。

（386-107）逢賈島七絕

張籍
僧房逢著款冬花，出寺行吟日已斜。
十二街中春雪遍，馬蹄今去入誰家。

（386-108）山中酬人七絕

張籍
山中日暖春鳩鳴，逐水看花任意行。
向晚歸來石窗下，菖蒲葉上見題名。

（386-109）弱柏院僧影堂七絕

張籍
弱柏倒垂如線蔓，簷頭不見有枝柯。
影堂香火長相續，應得人來禮拜多。

（386-110）題故僧影堂七絕

張籍
香消雲鎖舊僧家，僧刹殘形半壁斜。
日暮松煙寒漠漠，秋風吹破紙蓮花。

（386-111）無題七絕

張籍
桃溪柳陌好經過，燈下妝成月下歌。
為是襄王故宮地，至今猶有細腰多。

（386-112）山禽七絕

張籍
山禽毛如白練帶，棲我庭前栗樹枝。
獼猴半夜來取栗，一雙中林向月飛。

（386-113）秋山七絕

張籍
秋山無雲複無風，溪頭看月出深松。
草堂不閉石床靜，葉間墜露聲重重。

（386-114）玉真觀七絕

張籍
台殿曾為貴主家，春風吹盡竹窗紗。
院中仙女修香火，不許閒人入看花。

（386-115）蠻中七絕

張籍
銅柱南邊毒草春，行人幾日到金麟。
玉鐶穿耳誰家女，自抱琵琶迎海神。

（386-116）贈道士七絕

張籍
茅山近別剡溪逢，玉節青旄十二重。
自說年年上天去，羅浮最近海邊峰。

（386-117）重平驛作七絕

張籍
茫茫菰草平如地，渺渺長堤曲似城。
日暮未知投宿處，逢人更問向前程。

（386-118）宿天竺寺，寄靈隱寺僧七絕

張籍
夜向靈溪息此身，風泉竹露淨衣塵。
月明石上堪同宿，那作山南山北人。

（386-119）酬朱慶餘七絕

張籍
越女新妝出鏡心，自知明豔更沉吟。
齊紈未是人間貴，一曲菱歌敵萬金。

（386-120）寒食憶歸七絕

張籍
京中曹局無多事，寒食貧兒要在家。
遮莫杏園勝別處，亦須歸看傍村花。

（386-121）寒食雜言

張籍
綠楊枝上五絲繩，枝弱春多欲不勝。
唯有一年寒食日，女郎相喚擺階o3。

（386-123）句五律

張籍
韓公國大賢，道德赫已聞。
時出為陽山，爾區來趨奔。
韓官遷掾曹，子隨至荊門。
韓入為博士，崎嶇送歸輪。
